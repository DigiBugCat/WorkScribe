Search returns moments, placed back in the book

A search doesn't return a list of files. It returns moments (a turn in a call, 14:32 into a voice memo, a frame of a site video, a PDF page, a photo, a clip) and puts each one back on the day it happened, in time order. The month ribbon shows where they cluster. Ask is a margin conversation beside the moments it's about.
