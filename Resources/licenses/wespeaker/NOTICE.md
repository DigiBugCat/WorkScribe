# Legacy WeSpeaker v2 conversion

The downloaded `wespeaker_v2.mlmodelc` is a Core ML conversion distributed by
[FluidInference/speaker-diarization-coreml](https://huggingface.co/FluidInference/speaker-diarization-coreml).
The upstream WeSpeaker implementation uses Apache-2.0 (full text in `LICENSE`).
The exact conversion is pinned in `../fluidaudio/MODEL-REVISION.txt` and
`MODEL-SHA256.json`; its model publisher's README is retained here.

**Redistribution remains unresolved for this exact legacy weight conversion.**
The publisher explicitly excludes `wespeaker_v2.mlmodelc` from its current
Community-1/CC-BY-4.0 provenance confirmation. An implementation license alone
is not proof of weight provenance. Do not describe the CC-BY notice as covering
this file or redistribute these weights without clarifying the chain of rights.
Bootstrap obtains this model directly from the publisher for local builds; the
app bundle does not contain model weights. No inspected license explicitly
forbids redistribution; missing provenance is a separate unresolved issue.
