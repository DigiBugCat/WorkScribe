# Apple’s on-device stack for WorkScribe

Researched **2026-10-13**. **Docs** = Apple documentation/WWDC, including API availability metadata; **Source** = inspected repository code; **Report** = developer measurements, not reproduced here. Recommendations are engineering judgments. No models were benchmarked locally.

**Recommendation:** add Apple backends, retain Gemma/Nemotron, and target **macOS 27 Golden Gate**, released September 14, 2026 ([Apple](https://www.apple.com/newsroom/2026/09/major-updates-for-apples-software-platforms-are-now-available/)). Minimum versions below describe API availability, not a proposed compatibility obligation.

## Foundation Models: complement Gemma first

**Docs:** distinguish model generations. Apple describes AFM 3 Core as **3B dense parameters**, and Core Advanced as **20B total, 1–4B active**, hardware dependent; this does not establish which variant every framework client receives ([research](https://machinelearning.apple.com/research/introducing-third-generation-of-apple-foundation-models)). macOS 26’s documented context is **4,096 tokens**; WWDC26 demonstrates **8,192** for the macOS 27 system model. Some current prose still says 4,096: query `SystemLanguageModel.contextSize` and `tokenCount(for:)`, including instructions, schemas, tool results and output in the budget ([26 limit](https://developer.apple.com/documentation/technotes/tn3193-managing-the-on-device-foundation-model-s-context-window), [27 demonstration, 2:46](https://developer.apple.com/videos/play/wwdc2026/241/)). Never send an entire long meeting blindly.

`LanguageModelSession` supports `respond`, `streamResponse` and `Tool`; streaming returns cumulative snapshots, including partially generated structures. `@Generable` and `@Guide` constrain types/ranges, eliminating malformed JSON, **not hallucinated facts** ([guided generation](https://developer.apple.com/documentation/foundationmodels/generating-swift-data-structures-with-guided-generation), [streaming](https://developer.apple.com/documentation/foundationmodels/generating-content-and-performing-tasks-with-foundation-models)). Expose bounded local retrieval as a tool; validate cited chunk IDs and quotations in Swift.

On 27, `Attachment` adds image understanding and `OCRTool` supplies structured image text. These can complement document extraction but should not replace deterministic OCR provenance ([image session](https://developer.apple.com/videos/play/wwdc2026/237/)). Explicitly instantiate the on-device model; Apple Intelligence must first download its assets. The framework also supports cloud providers, so merely importing it does not establish offline behavior.

**Source:** `NoteEnhancer.swift` already uses `NotePlanner`, `NotePrompt`, and Gemma through `ws_generate_text(..., 8192, ...)`. Preserve planning/application semantics; swap generation behind `NoteEnhancing`.

| WorkScribe task | Concrete comparison and choice |
|---|---|
| Shorthand enhancement | Strong Apple candidate: one note plus its excerpts → typed enhanced text and evidence IDs. Gemma keeps pinned weights and prompt control; compare factual additions and preserved acronyms. |
| Briefs/action items | Apple handles chunk extraction and typed assignee/deadline fields; hierarchical reduction remains necessary. Unknown owners/dates must stay optional. Keep Gemma until attribution tests pass. |
| Live question detection | Try a small typed classification/extraction request on a rolling window, but debounce it. Neither model has demonstrated continuous-detector latency here. |
| Chat with citations | Both require retrieval, abstention and application validation. Apple’s 27 context now matches the current **configured** Gemma window, not necessarily Gemma’s maximum. Neither guarantees grounded answers. |

**Docs:** availability depends on Apple Intelligence/device/region/model readiness; check `availability`. Query `supportedLanguages`/`supportsLocale(_:)` rather than assuming English-only or universal coverage ([model](https://developer.apple.com/documentation/foundationmodels/systemlanguagemodel), [languages](https://developer.apple.com/documentation/foundationmodels/supporting-languages-and-locales-with-foundation-models)). Apple’s published 26.1 list includes English, Chinese, Japanese, Korean, Vietnamese, Danish, Dutch, French, German, Italian, Norwegian, Portuguese, Spanish, Swedish and Turkish ([support](https://support.apple.com/en-mide/121115)); runtime checks govern newer versions.

Background generation is allowed but can be throttled; Apple’s WWDC26 lab says foreground Mac on-device calls are not rate-limited. No fixed requests/minute SLA is supplied; queue, cancel obsolete work and retry later ([lab, 11:22](https://developer.apple.com/videos/play/wwdc2026/8121/)). Guardrails inspect input/output and can refuse sensitive meeting material; configurable levels are not a universal bypass ([safety](https://developer.apple.com/documentation/foundationmodels/improving-the-safety-of-generative-model-output)).

LoRA exists, but Apple’s final **26.0.0 adapter toolkit does not support OS 27+**; adapters require matching system versions, approximately 160 MB each, and deployment entitlement. Skip it for this fork ([toolkit](https://developer.apple.com/apple-intelligence/foundation-models-adapter)). macOS 27 instead offers the `LanguageModel` provider protocol, including `MLXLanguageModel`/`CoreAILanguageModel`, useful for a shared local-model interface ([provider session](https://developer.apple.com/videos/play/wwdc2026/339/)).

**Report:** one M4 Max benchmark records Apple FM at 269 ms first token/85.2 tokens/sec versus Gemma E2B llama.cpp at 41 ms/119.2 tokens/sec, three short-chat trials. Different models; 27 MB Apple in-process memory excludes its service. These are not WorkScribe or current AFM3 results ([benchmark](https://github.com/john-rocky/apple-silicon-llm-bench)). Developer reports praise small structured tasks but describe hallucination/context failures; these older reports cannot establish AFM3 quality ([discussion](https://www.reddit.com/r/appledevelopers/comments/1q31zww/)). Measure factuality, citation validity and p50/p95 latency while ASR and embeddings run concurrently.

## SpeechAnalyzer: worthwhile optional ASR

**Docs:** macOS **26+** `SpeechAnalyzer` + `SpeechTranscriber` provides on-device, long-form conversational recognition, asynchronous audio input/results, volatile hypotheses and final text with audio timing. It is designed for distant speakers and low latency, but Apple supplies no universal latency/WER guarantee ([WWDC25](https://developer.apple.com/videos/play/wwdc2025/277/)). Public result attributes expose timing/confidence, **not speaker identities**: retain Nemotron diarization and WeSpeaker profiles ([attributes](https://developer.apple.com/documentation/speech/speechtranscriber/resultattributeoption)).

Use `isAvailable`, `supportedLocales` and `installedLocales`; supported languages and downloadable locales differ from Foundation Models ([API](https://developer.apple.com/documentation/speech/speechtranscriber)). The report below counted roughly 30 locales, not 30 distinct languages; obtain the actual list on the target Mac. `AssetInventory.assetInstallationRequest(supporting:)` → `downloadAndInstall()` installs shared system assets; reservations are limited (`maximumReservedLocales`). Downloads require connectivity once; inference is local. Check readiness again because unused reservations can be reclaimed ([assets](https://developer.apple.com/documentation/speech/assetinventory)). Convert with `AVAudioConverter` to `bestAvailableAudioFormat(compatibleWith:)`; commit only finalized ranges.

**Report:** Lyonesse measured 2.12%/4.56% WER on LibriSpeech clean/other, M2 Pro/macOS 26.5.1. Its follow-up found Parakeet v2 at 2.01%/3.40%. This is read English, not meetings or **Nemotron streaming**; batch speed does not establish partial-result latency ([first study](https://lyonesse.app/blog/apple-speech-api-benchmark.html), [follow-up](https://lyonesse.app/blog/parakeet-moss-apple-speech-benchmark.html)). Developers also report successful SpeechAnalyzer + separate FluidAudio diarization ([firsthand report](https://developer.apple.com/forums/thread/819525)). Add Apple for supported non-English locales and A/B testing; keep Nemotron as default pending meeting-quality and speaker-alignment tests.

## Ranked adoption

Effort estimates are implementation scope, not delivery promises. All rows are **Docs-backed APIs / proposed uses**.

| Rank / decision | API, minimum macOS | WorkScribe benefit / effort |
|---|---|---|
| 1 — Adopt | `RecognizeDocumentsRequest`, `DocumentObservation` — **26** | OCR with paragraphs, tables/lists and coordinates. Render scanned PDF pages with PDFKit; retain page/bounding-box provenance. Screenshots benefit too. **Medium.** [Docs](https://developer.apple.com/documentation/vision/recognizedocumentsrequest) |
| 2 — Adopt | `EKEventStore.requestFullAccessToEvents()` — **14** | Upcoming-meeting context, attendees and calendar links; local event-store reads. Requires `NSCalendarsFullAccessUsageDescription`; OS calendar accounts may sync independently. **Small–medium.** [Docs](https://developer.apple.com/documentation/eventkit/ekeventstore/requestfullaccesstoevents(completion:)) |
| 3 — Pilot | Foundation Models / SpeechAnalyzer — **26**; new provider APIs — **27** | Bounded generation and multilingual ASR described above. **Medium each**, including evaluation. |
| 4 — Adopt selectively | `IndexedEntity` — **15**; `AppIntent` — **13**; `SpotlightSearchTool` — **27** | Surface meetings and open/search actions through Spotlight/Shortcuts/Siri; pilot local RAG over donated items. Keep SQLite/EmbeddingGemma canonical. **Medium.** [Entities](https://developer.apple.com/documentation/appintents/indexedentity), [intents](https://developer.apple.com/documentation/appintents/appintent), [RAG](https://developer.apple.com/videos/play/wwdc2026/246/) |
| 5 — Adopt capture option | `CATapDescription`, `AudioHardwareCreateProcessTap`, aggregate device — **14.2** | Audio-only per-process capture avoids tying capture to a display. Current `Capture.swift` uses ScreenCaptureKit; retain it for screenshots. Test device changes/drift. **Medium–large.** [Sample](https://developer.apple.com/documentation/coreaudio/capturing-system-audio-with-core-audio-taps) |
| 6 — Profile / watch | `MLComputePlan` — **14.4**; `MLTensor`, `MLState` — **15**; `AIModel`, `ComputeUnitKind` — **27** | Inspect execution placement; compute-unit allowances do not guarantee ANE execution. Stateful models can retain KV caches. Watch Core AI `.aimodel` conversion before replacing working FluidUse Core ML. **Small profiling; large migration.** [Plan](https://developer.apple.com/documentation/coreml/mlcomputeplan-1w21n), [tensor](https://developer.apple.com/documentation/coreml/mltensor), [state](https://developer.apple.com/documentation/coreml/mlstate), [Core AI](https://developer.apple.com/documentation/coreai) |
| 7 — Small utility | `NLLanguageRecognizer`, `NLTagger` — **10.14** | Text-language routing, tokenization/entities; not audio language detection or question understanding. **Small.** [Docs](https://developer.apple.com/documentation/naturallanguage) |

**Skip for the automatic pipeline:** Writing Tools (`NSTextView`, `NSWritingToolsCoordinator`, **15**) is user-driven editing and can involve cloud-backed features; it cannot enforce this assistant’s local-only generation contract ([docs](https://developer.apple.com/documentation/appkit/writing-tools)). Mac Live Activities currently mirror nearby **iPhone** activities; ActivityKit has no native macOS availability. Keep `MenuBarExtra` recording status ([Mac](https://developer.apple.com/macos/), [ActivityKit](https://developer.apple.com/documentation/activitykit)). Explicitly exclude PCC/cloud providers despite their availability in Foundation Models.
